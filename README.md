# 💎 HIRANYA – Jewellery E-Commerce Website

A modern and responsive jewellery e-commerce website developed using HTML, CSS, and JavaScript during my internship.

## 📌 About the Project

**HIRANYA** is a responsive jewellery e-commerce frontend developed during my internship. The project focuses on creating a premium, user-friendly interface for showcasing jewellery collections and providing an intuitive shopping experience.

The website includes multiple pages and interactive features such as product browsing, search, category filtering, product details, shopping cart, checkout, digital gold, about, and contact sections.

## ✨ Features

- 🏠 Home Page
- 💎 Jewellery Collections
- 🔍 Search & Category Filtering
- 📦 Product Details
- 🛒 Cart & Checkout
- 🪙 Digital Gold
- ℹ️ About & 📞 Contact
- 👨‍💼 Admin Panel UI
- 📱 Responsive Design

## 🛠️ Tech Stack

HTML5 • CSS3 • JavaScript
